# CV project description

**Retail Sales Analytics & Forecasting** | Python, Power BI, Pandas, scikit-learn

- Analysed 421,570 weekly store-department sales records spanning 45 stores, using Python to prepare data and evaluate sales trends, holidays, store type and store size.
- Developed visual analytics showing $6.74B in historical sales and an approximately 7.84% higher average in observed holiday weeks than in non-holiday weeks.
- Presented a time-ordered forecasting comparison: Histogram Gradient Boosting reached $1,294.90 MAE versus $1,778.68 for a 52-week seasonal-naive baseline on 32,938 holdout observations.
